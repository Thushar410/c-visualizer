University C Lab Exam — Essential Viva Questions

1. What is the difference between Call by Value and Call by Reference?

Call by Value: Function receives a copy of the argument. Changes made inside the function do NOT affect original variables.
Call by Reference: Function receives the memory address (pointer) of variables. Dereferencing allows direct mutation of original variables in the caller's stack frame.

2. What does ptr + 1 actually do? (Pointer Arithmetic)

It adds 1 * sizeof(*ptr) bytes, NOT 1 byte! For an int* (4 bytes), ptr + 1 adds 4 bytes. For a double*, it adds 8 bytes.

3. How are 2D Arrays stored in C memory?

C stores 2D arrays in Row-Major Order (Row 0 is placed in memory, immediately followed by Row 1). Physical memory is flat and 1D; the element mat[i][j] is accessed at address Base + (i * COLS + j) * sizeof(element).

4. What is a Dangling Pointer vs NULL Pointer vs Wild Pointer?

NULL Pointer: Explicitly points to address 0 (safe to check ptr == NULL).
Dangling Pointer: Points to memory that was already freed with free().
Wild Pointer: An uninitialized pointer holding random garbage address.

5. What is the difference between malloc() and calloc()?

malloc(size): Allocates raw bytes on Heap with uninitialized garbage values.
calloc(n, size): Allocates memory and automatically initializes all bits to zero (0).

6. What is the Arrow Operator (->) in C?

The arrow operator ptr->member is shorthand for (*ptr).member. It is used when accessing fields of a structure through a pointer.

7. Why is the Null Terminator '\0' necessary in strings?

In C, character arrays do not store string length. Functions like printf("%s") and strlen() rely on reading sequential bytes until encountering the byte '\0' (ASCII 0) to know where the string ends.

8. What causes a Stack Overflow in recursion?

Every recursive call allocates a stack frame. If the base case is missing or incorrect, recursive calls continue endlessly until the limited Stack memory space is exhausted, resulting in a segmentation fault.
